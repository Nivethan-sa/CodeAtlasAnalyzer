Frequently asked

Why do I need a GitHub token?

GitHub allows only 60 requests an hour without one; a token raises that to 5,000 and lets CodeAtlas see private and organisation repos. It is verified with GitHub, then stored on your account.

Which languages are supported?

JavaScript/TypeScript and Python get the deepest analysis; other languages are detected from file types and manifests.

Does the AI chat see my code?

It sends relevant source snippets from the repo you scanned to Gemini so it can answer. Only scan repos you are comfortable sharing that way.

Can I sign in with Google?

Yes, when the server has Google sign-in configured. The button shows on the Sign in and Sign up pages.
